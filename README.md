# projeto_sistemaplaylist2026
Um algoritimo que funciona como um sistema de playlist, onde é possivel adicionar alguma musica, remover aquela musica e lista a biblioteca de musicas, após inserir as musicas na biblitoeca é possivel criar uma playlist utilizando como base o BPM da musica para determinar o humor da playlist, é possivel também reproduzir a primeira musica da playlista do humor escolhido, exibir a fila do humor escolhido, o histórico de musicas já reproduzidas, mostrar as estatisticas (musicas totais na biblioteca, musicas por fila de humor, musicas já reproduzidas) e por fim gerar dados aleatorios utilizando a biblioteca Faker.
# Como Usar? (Windows)
Crie um ambiente virtual na pasta do arquivo e ative-o
```
python -m venv .venv
.venv\Scripts\activate
```
Instale os "requirements.txt"
```
pip install -r requirements.txt
```
Execute o algoritimo estando na pasta correta no terminal utilizando o comando 
```
python main.py
```
Depois de utilizar o comando acima, o menu principal será mostrado no console, apenas digite o número da opção que deseja executar.
